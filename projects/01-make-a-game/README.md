# Project 1: Make a Game

**Time:** about 90 minutes to 2 hours, less if you've done some of this before

**You need:** an AI coding agent such as Claude Code or Codex, set up ([see the setup guide](../../SETUP.md)). Nothing else.

**You'll leave with:** a small game that runs in your browser, and a working understanding of the terminal, files, if statements, loops, git, acceptance criteria, handing work to an AI helper, and checking work you didn't do yourself.

## What happens

The AI starts by asking you a few quick questions about what you already know, so the lesson fits you. Then you'll:

1. Look around your computer from the terminal.
2. Write down what "done" means for your game before anything gets built.
3. Set up git so you can always go back.
4. Watch the AI hand the build to a helper agent, and see why that's how good managers work.
5. Change the game yourself, by asking and by hand.
6. Break it on purpose and learn to read the error.
7. Check the game against your definition of done, then have a skeptical second agent try to find what you missed.
8. Write down what you learned, in your own words.

Expect to be asked to guess what will happen, and to explain ideas back. That's the point. If you just want a game, ask the AI for one in a sentence; this project is about understanding how it's built.

## How to start

1. Make a new, empty folder somewhere on your computer. Name it `my-game`.
2. Open that folder in your AI agent's app. In the Claude app, make sure you're on the **Code** tab, not Chat. (The [setup guide](../../SETUP.md) shows how.)
3. Check the settings next to where you type:
   - **Permission mode:** the one that asks before acting. That's **Manual** in Claude Code, **Ask for approval** in Codex.
   - **Model and effort:** **Opus 5.5** at **Medium** effort in Claude Code; **GPT-6.1 Sol** at **Medium** in Codex. This keeps you from running out of usage partway through.
4. Start a **new session** (a fresh conversation in your agent). Open [PROMPT.md](PROMPT.md), click the **Copy raw file** button (the two overlapping squares near the top right of the file), and paste it in as your first message.

**Yes, paste the whole file.** It's much longer than anything you'd normally type into an AI, on purpose: it's the full set of instructions that turns the AI into your teacher. Don't trim or summarize it.

That's it. The AI takes it from there.

## When you're done

Keep your `my-game` folder. Project 2 builds on it, and your `LEARNING_LOG.md` helps the next project pick up where this one left off.
